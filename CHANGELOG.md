# Changelog

## 2.2.0

- Completed a tab-by-tab premium visual redesign for iPhone and iPad.
- Replaced letter and emoji navigation marks with consistent embedded vector icons.
- Increased form readability, touch targets and field spacing across all workspaces.
- Added safe-area-aware portrait and landscape layouts for notched iPhones and iPads.
- Refined expanded, stowed and off-canvas navigation states.
- Rebuilt mobile W&B loading rows as readable cards instead of a wide table.
- Improved TOLD mobile cards, report actions, signoff layout and phase panels.
- Added horizontal aircraft-profile selection and scrollable performance subtabs on mobile.
- Corrected the four-column fuel summary and improved route metric wrapping on narrow phones.
- Standardized panel padding, toolbar actions, empty states, checklists, saved-flight cards and settings.

## 2.1.0

- Added full takeoff-and-landing-data (TOLD) calculation workspace.
- Added separate departure and arrival weather/runway conditions.
- Added configuration-specific POH/AFM takeoff and landing datasets.
- Added TORA/TODA/ASDA/LDA comparisons, margins and optional accelerate-stop distance.
- Added configurable TOLD speed labels and report exports.
- Added phase-specific surface, wind, slope and planning-factor corrections.
- Added out-of-range lockout and stale-report invalidation.
- Added expanded/stowed iPad navigation and off-canvas iPhone/portrait navigation.
- Added responsive card rendering for TOLD results on narrow devices.
- Added TOLD and responsive-device validation documentation.
- Hardened local-storage parsing against null/corrupt values.

## 2.0.0

- Initial real-world supplemental planning, W&B, briefing and aircraft-profile release.
