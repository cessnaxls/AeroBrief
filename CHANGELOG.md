# Changelog

## 2.1.0

- Added full takeoff-and-landing-data (TOLD) calculation workspace.
- Added separate departure and arrival weather/runway conditions.
- Added configuration-specific POH/AFM takeoff and landing datasets.
- Added TORA/TODA/ASDA/LDA comparisons, margins and optional accelerate-stop distance.
- Added configurable TOLD speed labels and report exports.
- Added phase-specific surface, wind, slope and planning-factor corrections.
- Added out-of-range lockout and stale-report invalidation.
- Added expanded/stowed iPad navigation and off-canvas iPhone/portrait navigation.
- Added responsive card rendering for TOLD results on narrow devices.
- Added TOLD and responsive-device validation documentation.
- Hardened local-storage parsing against null/corrupt values.

## 2.0.0

- Initial real-world supplemental planning, W&B, briefing and aircraft-profile release.
