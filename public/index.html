REGULATORY POSITION

What this app is—and is not

This software is not FAA certified or individually “FAA approved.” It is designed as a supplemental EFB using authoritative FAA/NWS sources where public machine access exists. Part 91 pilots remain responsible for current and complete information. Part 91K/121/125/135 use requires the operator’s EFB program and FAA authorization.

AC 91-78AAC 120-76EFAA Aeronautical Data
BEFORE OPERATIONAL USE

AeroBrief is a supplemental EFB—not an approval.

This build uses FAA/NWS data endpoints for embedded weather and TFR information. It cannot guarantee completeness, connectivity, source availability, aircraft-data correctness, or operational authorization.

  • Load only aircraft data verified against the current aircraft records and POH/AFM.
  • Use FAA Flight Service or FAA NOTAM Search for a complete NOTAM/briefing record.
  • Maintain current charts and a suitable backup appropriate to your operation.
  • For Part 91K, 121, 125 or 135, use only under your operator’s authorized EFB program.
